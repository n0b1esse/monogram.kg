# monogram.kg

Сайт концепт стора MONOGRAM в Бишкеке. Официальный дистрибьютор премиальных европейских брендов. Контент и фото взяты из Instagram магазина.

## Страницы

- `index.html` — главная: баннер, цифры из Instagram, подборка фото, магазины
- `catalog.html` — каталог из 12 живых фото с фильтром и увеличением по клику
- `about.html` — о магазине и преимущества
- `contacts.html` — адреса, карта, частые вопросы, форма в WhatsApp

Общие стили в `styles.css`, скрипты в `script.js`, фото в `assets/`. Без сборки, чистый HTML, CSS и JavaScript.

## Как посмотреть

```sh
python -m http.server 8099
```

Открыть http://127.0.0.1:8099
